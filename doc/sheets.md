## SH1106 OLED 状态显示

屏幕为 1.3 寸、128×64、7 针 SH1106 模块，使用 **4 线 SPI** 模式。

| OLED 引脚 | ESP32-S3 引脚 | 用途 |
| --- | --- | --- |
| GND | GND | 共地 |
| VCC | 3V3 | 电源 |
| D0 / SCL | GPIO12 | SPI 时钟 |
| D1 / SDA | GPIO11 | SPI MOSI |
| RES / RST | GPIO46 | 低电平复位 |
| DC / D-C | GPIO9 | 命令／数据选择 |
| CS | GPIO10 | 片选 |

保持模块为 4 线 SPI 模式，CS 接 GPIO10。资料包包含 0.96 寸 SSD1306 示例；当前固件按 SH1106 初始化，以 8 页、每页 128 字节写入，列地址偏移为 2。SPI2 使用 mode 0、1 MHz，无 MISO。禁用 DMA 时，每次 SPI 传输不超过 64 字节，每页 128 字节分两次发送；设置 `max_transfer_sz` 不能扩大非 DMA 的硬件 FIFO 上限。

GPIO46 是启动配置引脚；外接屏幕不得在芯片复位采样时强拉高，避免影响下载模式。若连接屏幕后无法进入烧录模式，先断开 RES 排查。引脚功能参考 [ESP32-S3 官方开发板说明](https://documentation.espressif.com/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html)。

## 状态与控制器界面

固定单页、英文＋图标，使用原有 1024 字节帧缓冲。显示任务保持优先级 1、不绑定核心；每次刷新后阻塞 100 ms，实际刷新间隔包含绘图和 SPI 传输时间。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 左侧显示 `ONLINE / OFFLINE / STANDBY` 模式，居中显示像素表情 `ᗜ_ᗜ`；右侧 NS 紧邻 USB 状态方框，实心表示已枚举且未挂起，空心表示未枚举或已挂起 |
| 中部大字 | `READY / ACTIVE / IDLE / RUNNING / WAITING / STOPPED / FINISHED / ERROR / NO SCRIPT` |
| 时间行 | `T` 或 `LAST` 均位于状态大字右下，靠右且底部对齐；等待时 `W` 位于 `T` 上方，错误说明也放在状态右侧 |
| 错误行 | 错误时用简短英文原因及错误码代替时间，例如 `DIV BY ZERO 8`、`NO MEMORY 12` |
| 下方控制器图 | 方向键、ABXY、肩键、辅助键及双摇杆，按键高亮与模式无关 |

按键图中的 `H` 表示 HOME、`C` 表示 CAPTURE；肩键为 ZL/L/R/ZR，中间辅助按键从左到右为 `- C H +`。L/R 圆圈中的点表示左右摇杆最新位置，外圈加粗表示摇杆按下。中心值为 128，Y 值越小越靠上。

控制图读取固件当前的 HID 报告，PC 控制、ECX 和旧板载脚本都可显示。按键与方向键松开后仍保留约 200 ms 高亮，避免漏掉短点击；连续切换方向时可能短暂同时显示之前和当前方向。高亮只表示当前或最近的输入，**不会延迟真实松键和摇杆回中**，也不保证 USB 主机已成功接收对应报告。

NS 方框使用 `tud_mounted() && !tud_suspended()`，拔线后进入 USB 挂起状态时变为空心，恢复通信后重新变为实心。主机休眠也会显示空心；没有 VBUS 检测电路时，这不是物理插线检测，也不能识别主机是否为 Nintendo Switch。

### 模式选择

ONLINE 表示电脑控制来源；OFFLINE 表示板载脚本会话，包括停止、完成或错误后保留的结果；STANDBY 表示尚无控制会话。这里的 ONLINE/OFFLINE 不是联网状态。

表情每隔随机 2.5–6.5 秒眨眼约 200 毫秒；默认表情保持随机 6–18 秒后，随机切换成笑脸 `ᗜˬᗜ` 或哭脸 `ᗜ˰ᗜ`，显示约 1.2–2.4 秒再恢复。动画由 OLED 刷新任务处理，不阻塞脚本运行。

1. 板载脚本运行或等待时，优先显示其状态。
2. 板载脚本没有运行且收到过 PC 控制报告时，显示 PC 活动。
3. 其他情况显示板载待机、停止、完成或错误状态；ECX 或有效旧脚本的会话显示 OFFLINE，其余显示 STANDBY。

初始状态为 READY。空的旧板载脚本显示 NO SCRIPT。停止／结束后保留本次运行时间，再次启动清零。板载脚本启动会清除 PC 活动记录，因此其结果可保留到收到新的 PC 控制报告为止。

PC 最近一次有效控制报告中，只要有按键按住、方向键未释放或任一摇杆轴不等于中心值 128，就持续显示 ACTIVE，不受报告间隔影响。全部释放并回中后，最近报告不足 60 秒仍显示 ACTIVE，达到 60 秒显示 IDLE。计时依据最近有效报告，因此释放报告会重新计时。握手、心跳、版本查询不算控制活动；板载执行期间被 BUSY 拒绝的报告也不算。这仍不能准确判断电脑脚本是否运行：空闲等待超过 60 秒会显示 IDLE，按住状态下通信中断则仍显示 ACTIVE。

LAST 最多占 9 个字符（53 像素）：不足 10 秒显示一位小数，之后显示整数秒，满 1 分钟改用整数分钟，满 1 小时改用整数小时，满 1 天改用整数天。所有模式的状态大字与右下信息底边同为 y=25；顶部栏下方不绘制分隔线，状态区下方保留 y=28 分隔线。手柄以屏幕中线 x=63.5 对称布局：方向键中心 x=13、ABXY 中心 x=114，双摇杆中心 x=45/82 且等高，肩键和中间辅助键也成对居中；肩键位于 y=31，与 y=28 分隔线之间空 2 行，与状态区下沿留白一致；中间 `- C H +` 位于 y=33，比 L/R 下移 2 像素。T、LAST、W 共用紧凑格式：不足 10 秒显示一位小数，10–59 秒显示整数秒，之后自动切换整数分／时／天；前缀和数字之间留一个空格，例如 `T 0.2S`、`LAST 12S`、`W 3M`。不再使用时:分:秒格式。默认 STANDBY 不显示 T，确定为板载会话后才显示；PC 来源显示 LAST。NO SCRIPT 不显示计时。等待剩余时间向上取整到秒；错误状态右侧显示原因。

不显示字节码地址、报告计数或十六进制输入数据。现有协议没有电脑端脚本名称、源代码行号或运行状态，因此不显示这些信息。

### 同步与故障处理

HID 当前报告和短按反馈通过短临界区复制为快照；脚本状态也使用快照。绘图、SPI 传输及 USB 发送均不持有显示快照锁。屏幕初始化或传输失败只记录日志，手柄继续运行。SPI 没有应答，固件不能检测屏幕是否实际连接。

驱动命令参考 [SH1106 数据手册](https://www.displayfuture.com/Display/datasheet/controller/SH1106.pdf)。首次上板请依次验证：上电显示 READY、启动脚本、延时显示 WAITING、停止后计时保持、重启脚本计时归零、自然结束显示 FINISHED，以及插拔 USB 后状态变化。

ECX 编译、下载及错误码定义见 [ECX 脚本指南](ecx-flash.md)。
